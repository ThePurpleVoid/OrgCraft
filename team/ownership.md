# Ownership: one writer per path

A thread edits only the paths it owns. Anything else is a request to that path's owner. Two exceptions, both as small separate PRs after the owner's PR merges: the UX writer may fix string resource files, and the test automation engineer may add test hooks. The CTO updates this file when a new path appears.

This file belongs to your repository: `agent-team init` writes it once and `sync` never touches it. **Rename the paths below to your repository's real layout** and delete rows for roles you do not use.
