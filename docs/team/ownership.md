# Ownership: one writer per path

A thread edits only the paths it owns. Anything else is a request to that path's owner. Two exceptions, both as small separate PRs after the owner's PR merges: the UX writer may fix string resource files, and the test automation engineer may add test hooks. The CTO updates `.agent-team/ownership.json` when a new path appears.

Generated from `.agent-team/ownership.json`: change that file (or the Studio's ownership table) and run `scripts/agent-team/sync.sh`.
